# 数学操作

执行下面的代码，计算一个数的指数次幂。

```javascript
console.log(Math.pow(3, 2));
console.log(Math.pow(9, 0.5));
console.log(Math.pow(-2, 3));
console.log(Math.pow(2, -2));
```

也可以使用幂运算符代替。

```javascript
console.log(3 ** 2);
console.log(9 ** 0.5);
console.log((-2) ** 3);
console.log(2 ** -2);
```

执行下面的代码，计算自然常数 e 的指数次幂。

```javascript
console.log(Math.exp(2));
```

执行下面的代码，计算一个数的平方根。

```javascript
console.log(Math.sqrt(9));
console.log(Math.sqrt(16));
```

执行下面的代码，截断数字的小数部分。

```javascript
console.log(Math.trunc(3.5));
console.log(Math.trunc(-2.1));
```

执行下面的代码，对数字四舍五入取整数。

```javascript
console.log(Math.round(2.3));
console.log(Math.round(-2.3));
```

执行下面的代码，对数字向上取整。

```javascript
console.log(Math.ceil(1.1));
console.log(Math.ceil(1.9));
console.log(Math.ceil(-1.1));
console.log(Math.ceil(-1.9));
```

执行下面的代码，对数字向下取整。

```javascript
console.log(Math.floor(2.3));
console.log(Math.floor(-2.3));
```

执行下面的代码，获取数字的绝对值。

```javascript
console.log(Math.abs(-10));
console.log(Math.abs(-3.14));
```

执行下面的代码，获取指定数字中的最大值。

```javascript
console.log(Math.max(1, 5, 3, 9));
```

执行下面的代码，获取指定数字中的最小值。

```javascript
console.log(Math.min(1, 5, 3, 9));
```

执行下面的代码，生成一个 0 到 1 之间的随机小数。

```javascript
console.log(Math.random());
```

执行下面的代码，判断数字正负，并返回标识符号。

```javascript
console.log(Math.sign(100));
console.log(Math.sign(0));
console.log(Math.sign(-100));
```

执行下面的代码，判断两个小数是否相等。

```javascript
function equal(a, b) {
	return Math.abs(a - b) < Number.EPSILON;
}
console.log(0.1 + 0.2 === 0.3);
console.log(equal(0.1 + 0.2, 0.3));
```

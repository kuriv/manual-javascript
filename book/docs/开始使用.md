# 开始使用

执行下面的代码，向页面文档流写入内容。

```javascript
document.write('Hello World!');
```

执行下面的代码，分别弹出不同的提示弹窗。

```javascript
alert('Hello World!');
confirm('Hello World !');
prompt('Hello World!');
```

执行下面的代码，分别打印不同的调试信息。

```javascript
console.log('Hello World!');
console.warn('Hello World!');
console.error('Hello World!');
```

执行下面的代码，解析模板字符串并向页面文档流写入内容。

```javascript
let num = 233;
document.write(`${num}`)
```

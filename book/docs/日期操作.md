# 日期操作

执行下面的代码，获取当前系统时间。

```javascript
const date = new Date();
console.log(date);
```

执行下面的代码，获取当前时间戳。

```javascript
console.log(Date.now());
```

执行下面的代码，获取当前完整年份。

```javascript
const date = new Date();
console.log(date.getFullYear());
```

执行下面的代码，获取当前月份。

```javascript
const date = new Date();
console.log(date.getMonth());
```

执行下面的代码，获取当前星期。

```javascript
const date = new Date();
console.log(date.getDay());
```

执行下面的代码，获取当前日期。

```javascript
const date = new Date();
console.log(date.getDate());
```

执行下面的代码，获取当前小时。

```javascript
const date = new Date();
console.log(date.getHours());
```

执行下面的代码，获取当前分钟。

```javascript
const date = new Date();
console.log(date.getMinutes());
```

执行下面的代码，获取当前秒。

```javascript
const date = new Date();
console.log(date.getSeconds());
```

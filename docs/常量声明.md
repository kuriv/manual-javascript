# 常量声明

常量在声明时必须进行初始化，并且不允许对其重新赋值。

```javascript
const num = 233;
console.log(num);
```

对于数组常量的修改则不会报错。

```javascript
const arr = [233, 666];
console.log(arr);
arr[1] = 'Hello World!';
arr.push(1.23);
console.log(arr);
```

此外，对于对象常量的修改也不会报错。

```javascript
const obj = {
	name: 'Tom'
};
console.log(obj);
obj.age = 18;
console.log(obj);
```

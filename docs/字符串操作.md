# 字符串操作

执行下面的代码，查找某个子字符串或元素第一次出现的位置。

```javascript
let string = 'Hello World!';
console.log(string.indexOf('l'));
console.log(string.indexOf('l', 4));
```

执行下面的代码，查找某个子字符串或元素最后一次出现的位置。

```javascript
let string = 'Hello World!';
console.log(string.lastIndexOf('l'));
```

执行下面的代码，根据下标获取字符串中单个字符。

```javascript
let string = 'Hello World!';
console.log(string[0]);
console.log(string.charAt(0));
console.log(string.charAt(string.length - 1));
```

执行下面的代码，截取字符串中指定位置的字符。

```javascript
let string = 'Hello World!';
console.log(string.substring(2, 4));
console.log(string.substring(string.length - 1, 1));
```

执行下面的代码，截取字符串中指定位置的字符。

```javascript
let string = 'Hello World!';
console.log(string.slice(2, 4));
console.log(string.slice(string.length - 1));
```

执行下面的代码，匹配字符串内容并替换。

```javascript
let string = 'Hello World!';
console.log(string.replace('l', '#'));
console.log(string.replaceAll('l', '#'));
console.log(string.replace(/l/g, '#'));
```

执行下面的代码，将字符串按指定分隔符拆分成数组。

```javascript
let string = 'Hello World!';
console.log(string.split(' '));
```

执行下面的代码，将所有字母转为小写。

```javascript
let string = 'Hello World!';
console.log(string.toLowerCase());
```

执行下面的代码，将所有字母转为大写。

```javascript
let string = 'Hello World!';
console.log(string.toUpperCase());
```

执行下面的代码，将任意数据转为字符串。

```javascript
let num = 233;
console.log(num.toString());
console.log(num.toString(2));
console.log(num.toString(16));
```

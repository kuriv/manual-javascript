# 类型转换

执行下面的代码，将变量强制转换为数值类型。

```javascript
let str = '233';
console.log(Number(str), typeof Number(str));
```

执行下面的代码，将变量强制转换为字符串类型。

```javascript
let num = 233;
console.log(String(num), typeof String(num));
```

执行下面的代码，将变量强制转换为布尔类型。

```javascript
let num = 0;
let str = 'Hello World!';
let arr = [];
let obj = {};
console.log(Boolean(num), typeof Boolean(num));
console.log(Boolean(str), typeof Boolean(str));
console.log(Boolean(arr), typeof Boolean(arr));
console.log(Boolean(obj), typeof Boolean(obj));
```
